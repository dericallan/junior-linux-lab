What Your Child Will Learn

We teach two powerful skill sets—Linux and Coding—in a fun, beginner-friendly way, tailored for ages 8-15.

Track 1

Linux Fundamentals

🐧 System Administration & CLI

Understand how operating systems actually manage files, folders, and network tasks. Students move past click-based interfaces and learn to talk directly to the CPU.

  • 🖥️ How operating systems work under the hood
  • 🐚 Using the Linux terminal & shell prompts
  • 📁 Navigating directories tree structures
  • 🛠️ Essential Linux command lines navigation
Track 2

Coding Fundamentals

💡 Programming Logic & Scripting

Learn the universal building blocks of coding. Students write clean logic sequences and scripts that store data, evaluate decisions, and automate actions.

  • 🧠 Programming logic & step-by-step thinking
  • 📦 Variables, data storage, and math ops
  • 🔄 Control flows: Loops and conditions
  • ⚙️ Reusable functions and modular scripts

Fun Projects They Will Build

Every lesson ends with a real, working application. Kids learn by writing code and executing commands—not just watching.

Project 1

🔢 Calculator

Build a working command-line calculator from scratch using code. Teaches basic math operators, inputs, and functional variables.

Project 2

🎮 Guessing Game

Program a number guessing game featuring interactive hints, validation logic, user input analysis, and scoring tallies.

Project 3

❓ Quiz Game

Create an interactive quiz console that loads multiple-choice questions, tracks performance metrics, and calculates scores.

Project 4

📁 File Organizer

Write a real Linux shell utility that automates desktop sorting, moving files to folders based on extensions.
